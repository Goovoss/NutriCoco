# Gestión del proyecto

## Metodología
Para este proyecto usé un enfoque Kanban personal — tablero con columnas
Backlog, Todo, In Progress y Done para ir moviendo tareas según avanzaba.

## Organización del trabajo
El desarrollo se dividió en fases:
1. Setup del proyecto (Vite, Tailwind, React Router)
2. Integración de APIs (USDA, Open Food Facts)
3. Componentes principales (BuscadorIngrediente, TarjetaIngrediente, ResumenNutricional)
4. Autenticación (registro, login, JWT)
5. Backend (Express, PostgreSQL, Render)
6. UX (CocoConsejo, biométricos, historial)
7. Despliegue (Vercel + Render)

## Herramientas
- GitHub para control de versiones
- Vercel para despliegue del frontend
- Render para despliegue del backend
- Trello para gestión de tareas
